使用 Portainer 管理 Docker 容器

简介

Portainer 是一个 Docker 可视化管理平台，用于图形化管理容器，镜像，网络和数据卷。

特性

1. Web 可视化管理 Docker

  • 查看/启停容器
  • 拉取镜像
  • 创建，编辑，删除容器
  • 查看日志，资源占用
  • 进入容器 Shell

2. 管理 Docker Compose

  • 可直接在 Web 页面中粘贴 docker-compose.yml
  • 一键部署 / 更新 / 回滚
  • 修改环境变量后重新部署

3. 权限与安全

  • 多用户登录
  • 角色权限控制
  • API Token

1. 确认安装 Docker

2. 创建 Portainer 数据卷用于持久化

3. 启动 Portainer
